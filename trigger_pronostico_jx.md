# Trigger Pronóstico Jornada

Ejecuta el pipeline completo y genera reporte HTML con pronósticos para la jornada.

**Datos generados:**
- Partidos cargados
- Predicciones (HARPO)
- Confianza por partido
- Noticias impactantes
- Oportunidades de apuesta (GAMBLER)
- Auditoría (TANGO)

**Salida:** HTML interactivo + estadísticas
